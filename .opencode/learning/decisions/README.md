# Owner Decisions

This directory is an immutable audit trail for machine-owner decisions made by the `improvement-approver` agent.

Create one fresh `YYYY-MM-DD-lrn-yyyymmdd-nnn-decision.md` file for every decision and never rewrite or delete an earlier record. Include:

- proposal ID and title;
- displayed evidence, scope, risk, validation, and rollback summary;
- the exact owner choice;
- timestamp and decision actor;
- conditions or corrections attached to the decision;
- resulting proposal status.

Invoking a command is not consent. The agent must present the decision packet and receive an explicit owner response before writing a decision file.
