# Learning Journal

The journal is an immutable evidence log, not a transcript store.

Create one new `YYYY-MM-DDTHHMMSSZ-short-label.md` file per cycle. Never edit or delete an earlier journal file. Each entry should include:

- the exact inspected source range and its bounded scope;
- new evidence or an explicit no-op result;
- proposal IDs created;
- uncertainty and validation already performed, if any.

Never record secrets, environment values, personal data, raw model reasoning, full conversations, or unreferenced copied content. Summarize evidence and link to the source commit, path, test, or short quotation needed to reproduce it.
